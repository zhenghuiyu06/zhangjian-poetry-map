# 张謇时空罗盘

一个围绕张謇诗歌、行旅地点与时代线索构建的交互式数字人文网站。项目以地图为主要入口，将诗歌原文、音视频资料、时间轴、人物关系和数据可视化组织在同一页面中，帮助用户从时间、空间与文本三个维度浏览内容。

## 在线访问

- 网站：[loveeti.top](https://loveeti.top)
- GitHub Pages：由本仓库 `main` 分支自动部署

## 主要功能

- **诗歌地图**：在地图中查看作品对应地点，并在地点与诗歌详情之间快速跳转。
- **全文搜索**：支持按标题、地点、主题、时间线索和诗歌文本搜索。
- **时间轴**：依据站内数据展示作品与相关事件的时间关系。
- **诗歌详情**：集中呈现诗文、注释、图片、音频及已确认的视频资料。
- **人物关系**：展示有资料依据的人物与作品关联。
- **数据可视化**：从地点、主题等维度观察站内作品数据。
- **本地资料问答**：不接入外部 AI API，仅根据网页内已有资料进行检索式回答，并可跳转至相关内容。
- **收藏功能**：收藏结果保存在当前浏览器本地。
- **附近作品**：经用户授权后，在浏览器本地计算距离最近的诗歌地点，不上传位置坐标。
- **响应式布局**：适配电脑、平板和手机端，并支持横屏浏览。

## 媒体资源

网站使用仓库内的本地媒体文件直接播放，不依赖哔哩哔哩等第三方视频页面。

```text
assets/
├── audio/      # 诗歌音频（MP3）
├── images/     # 诗歌图片（WebP）
├── posters/    # 视频封面（JPEG）
└── videos/     # 诗歌视频（MP4）
```

当前第 8 首诗尚无经过确认的本地视频，因此网页保留“本地视频待补充”状态，不使用不确定素材替代。

## 项目结构

```text
.
├── .github/workflows/deploy.yml  # GitHub Pages 自动部署
├── assets/                       # 网站媒体资源
├── CNAME                         # 自定义域名 loveeti.top
├── index.html                    # 网站主体、样式与交互逻辑
└── README.md                     # 项目说明
```

## 本地运行

克隆仓库后，在项目目录启动一个静态文件服务器：

```bash
python3 -m http.server 8000
```

然后在浏览器访问：

```text
http://localhost:8000
```

## 技术说明

- 原生 HTML、CSS 与 JavaScript
- [Leaflet](https://leafletjs.com/) 地图交互
- [Apache ECharts](https://echarts.apache.org/) 数据可视化
- GitHub Actions 与 GitHub Pages 自动部署
- 视频采用 H.264 + AAC 的 MP4 格式，兼顾网页播放与移动端兼容性

## 数据与隐私原则

- 网站原有数据按项目资料保留。
- 新增历史内容只使用能够核实的信息；无法确认的内容保持空缺或标注待补充。
- 本地资料问答不调用外部 AI API。
- 收藏、问答和距离计算均在浏览器端完成。
- 浏览器定位仅在用户主动授权后使用，网站不会保存或上传用户坐标。

## 兼容性

建议使用较新版本的 Chrome、Edge、Safari 或 Firefox。首次打开地图时需要联网加载地图库、可视化库与地图瓦片；仓库内的图片、音频和视频由网站自身提供。
