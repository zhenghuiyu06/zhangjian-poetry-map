资料核对与站点说明

所有新增文件均在 v3/。预览须从仓库根目录启动静态服务器，再打开 /v3/；原站的图片、朗读、影像及经典地图通过相对路径复用，不能只拷贝 v3/ 单独部署。

展览材料

馆方提供的《2026文献展相关设计.2(1).pdf》用于主视觉及挂幅风格参考；《张謇文旅汇总版(3).zip》中的「引言汇总」及「参展图书汇总」是展陈文字与书页关系的直接来源。GBK 文件名解码后读取；海安旧格式引言经 LibreOffice 转为 UTF-8 文本；合并单元格按不同书目与地点关系读取。

引言属策展综述。卡片仅将能够从表述认定为张謇话语且带来源的片段提为独立引录，仍待对读原典；未判定的内容保留在表录正文，不强行署作张謇原话。另见引言和每条书目附注。

        补充来源与待核

          超星与后续维护

          《古镇余西》（ISBN 9787567231399）已配馆方提供的超星专题。实测 ss.zhizhen.com/s?sw= 会跳登录，未采用为公共检索模板；其余书提供读秀入口和复制书名。没有把外链写成正式合作或馆藏授权。

          1. js/data.js：改引言、展区、地点、书、原文引录和书目关系；数组 records 的索引从零计。调整索引时同时更新 places[].refs 和 books[].refs。
          2. chaoxing.searchTemplate 留空；取得可验证的馆方 URL 模板后填 HTTPS 地址并保留 {query} 占位。可直接给 books[] 添加 chaoxing URL，优先于 ISBN 覆盖与模板。
          3. js/guide.js：补充地点坐标、地区非遗和风味、十个「第一」、年表、交通及公开出处。网站不依赖地图库、也不发请求更新这些字段。
          4. 更新原站派生内容可运行 node v3/build-derived.mjs。它仅写入 v3 下两个页面与一个路径修正版脚本。三个 IndexedDB store 及七境印章 key 与原站一致；必须是同协议、域名及端口才共用。
          5. 标题字为 Noto Serif SC（简体中文，700），以实际标题字集生成本地 WOFF；字体许可见 OFL。新增标题后可运行 prepare-visuals.py 重建子集。
